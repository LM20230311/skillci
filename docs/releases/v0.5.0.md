## Discover what to audit

SkillCI now inventories project Skills and instruction files before you choose what to audit.

- Add `skillci discover [path] --format markdown|json` for Codex, Claude Code, Cursor, and GitHub Copilot conventions.
- Return relative paths, shared-host labels, recognition evidence, stable JSON schema v1, and structured diagnostics.
- Skip symbolic links and declared generated directories; report incomplete scans rather than treating read failures as success.
- Include four-host fixtures, discovery-to-audit examples, and fixed-commit inventory verification for three public repositories.
- Support Cursor `.mdc` and legacy `.cursorrules` files in existing static audits.
- Upgrade minimatch and brace-expansion to patched versions for reported denial-of-service vulnerabilities.

```bash
npx skillci@0.5.0 discover .
npx skillci@0.5.0 discover . --format json
```
